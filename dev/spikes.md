# Что проверить в настоящем Foundry

Стенд (`dev/harness/`) имитирует Foundry: на нём работает настоящий код модуля, но часть движка
там упрощена. Ниже — то, что на стенде проверить нельзя или можно только приблизительно. Проверять
на Foundry v13 и v14 с системой dnd5e 5.x / 6.x.

Отмечено [x] — проверено 6 ноября 2026 в Foundry 14.370 (сборка для Node.js) с dnd5e 6.0.6:
ведущий и игрок в разных вкладках, сцена со стенами и дверью. На v13 не проверялось.

## Окна

- [x] Окно библиотеки и окно настройки открываются; шаблоны-партиалы (`trap-card.hbs`) подхватываются
      через `loadTemplates`.
- [x] В окне настройки при правке перерисовывается только правая карточка (`render({ parts: ["preview"] })`),
      поля не теряют фокус; обработчики, навешанные в `_onFirstRender`, работают после перерисовки.
- [ ] Перетаскивание карточки на карту ставит ловушку под курсором (`dropCanvasData`).

## Поведение области

- [x] Тип поведения `ssl_traps.trap` появляется в списке поведений области.
- [x] Поле `options` (`ObjectField`) сохраняется целиком при `behavior.update({ "system.options": … })`,
      без слияния со старыми ключами.
- [x] Вход токена в область: движение придерживается и продолжается (`pauseMovement` / `resumeMovement`),
      яма, капкан, сеть и сон останавливают его.
- [x] v14: ловушка встаёт на открытый уровень сцены.
- [x] Тип `ssl_traps.activator` («Триггер ловушки») есть в списке поведений; вход токена в
      область-триггер запускает ловушку, она бьёт всех в своей области; сама область ловушки
      с триггерами от шагов не срабатывает.
- [x] v14: триггер встаёт на тот же уровень сцены, что и ловушка (`region.levels`).
- [ ] Плита внутри ямы останавливает наступившего; плита снаружи только придерживает движение,
      и оно продолжается после эффекта.
- [x] Ловушку удаляют вместе с её триггерами (выделить все и Delete) — без ошибок в консоли.
- [x] Кнопка ▶ на карте у взведённой ловушки; пунктир от триггера к ловушке — в пиксель
      толщиной при любом масштабе (`--st-inv`, как у кнопок).
- [x] «Только вручную»: вход в область и на триггер ничего не делает, ▶ срабатывает.
- [ ] После обновления модуля мир перезапущен: без этого Foundry не знает тип `ssl_traps.activator`,
      и ловушка ставится без триггера (с предупреждением).
- [ ] Копия области-триггера (Ctrl+C / Ctrl+V) ссылается на ту же ловушку, что и оригинал.

## Метки на карте (`scripts/foundry/markers.mjs`, `layers.mjs`)

- [x] Метка кладётся в первичную группу (`PrimarySpriteMesh`, `sortLayer` чуть ниже токенов) и
      рисуется под токенами.
- [x] Туман войны: в неразведанной части метки не видно, в разведанной — затемнена, в поле зрения —
      как есть. В темноте без зрения — тоже не видно.
- [ ] Если `PrimarySpriteMesh` недоступен, метка падает обратно в `canvas.interface` (поверх всего) —
      в консоли предупреждение.
- [ ] Перерисовка при смене сцены: старые метки не остаются на новой (`canvasTearDown`).
- [ ] Значки Font Awesome в метке без устройства и на значках состояния — не пустые квадраты.
- [x] Появление со вспышкой проигрывается у игрока, когда ловушку показали.

## Вспышка срабатывания (`scripts/foundry/fx.mjs`)

- [ ] Свой эффект лежит над токенами, под туманом.
- [ ] Игрок, который не видит место (за стеной, в темноте), вспышку не видит
      (`canvas.visibility.testVisibility`); звук слышит.
- [ ] С Sequencer и JB2A эффект берётся оттуда.

## Обнаружение (`scripts/foundry/actions.mjs`, `scene.mjs`)

- [x] Прямая видимость: `CONFIG.Canvas.polygonBackends.sight.testCollision(origin, point, { type: "sight", mode: "any" })`
      — стены и закрытые двери мешают заметить, открытая дверь — нет; односторонние стены и окна
      ведут себя как в Foundry.
- [x] «Заметить с»: `scene.grid.measurePath([p, q]).distance` между ближайшими клетками токена и
      ловушки — 10 фт через одну клетку, по диагонали — по правилу диагоналей сцены (5/5/5 или
      5/10/5); на гексах и без сетки — разумно.
- [x] Пассивная Внимательность срабатывает у активного ведущего на `updateToken`.
- [x] Режим «Сообщить мне»: шёпот только ведущим, уведомление, кнопки в сообщении работают у всех ведущих.

## Карточка срабатывания (`scripts/foundry/card.mjs`)

- [x] Спасбросок игрока: кнопка видна только владельцу персонажа и ведущему; `actor.rollSavingThrow`
      с окном dnd5e, сообщение броска в чате; итог доходит до ведущего по сокету (`trapSave`) и
      попадает в карточку (`message.update` с флагом `resolution`).
- [ ] Два игрока бросают одновременно — оба итога в карточке (очередь изменений у ведущего).
- [x] Урон после спасбросков: последний бросок — отдельное сообщение с кубиками урона (виден ли
      бросок с Dice So Nice), карточка обновилась; «Бросить урон» раньше — тоже.
- [x] «Нанести» и «Нанести всем»: урон через `actor.applyDamage` с сопротивлениями, состояние
      наложено, кнопки исчезают; после перезагрузки чата карточка такая же.
- [ ] Карточка «только ведущему»: при спасбросках игроков она шёпотом уходит и владельцам целей.

## Левая панель (`scripts/foundry/controls.mjs`)

- [x] Группа «Западня: ловушки» появляется после «Регионов», с черепом. Слой она не трогает:
      в v13–v14 включённый слой сам переключает панель на «свою» группу, и кнопки модуля пропадали.
      Нажали на череп — открылось окно (после перезагрузки само не открывается).
- [x] Кнопки «Библиотека», «Мои ловушки», «Ловушки этой сцены» открывают окно на своей вкладке.
- [x] Переключатель кнопок на карте подсвечен по настройке и меняет её; панель перерисовывается.
- [x] Кнопки на панели токенов больше нет (0.2.3).
- [x] «Выбрать и поправить область ловушки» переводит в «Регионы» с инструментом «Выбрать»:
      области ловушек и триггеров выделяются и правятся.
- [ ] Ключ на карте: выделенный токен остаётся выделенным после щелчка по кнопке (щелчок не уходит
      на холст), попытка обезвредить проходит.

## Кнопки ведущего (`scripts/foundry/gm-hud.mjs`, `chat.mjs`)

- [x] Кнопки с глазом встают в `#hud` и двигаются вместе с картой при прокрутке и масштабе
      (`canvasPan` → `--st-inv`), щелчок по кнопке не снимает выделение токенов.
- [ ] После перерисовки `#hud` самим Foundry (выбор токена, открытие его HUD) кнопки на месте.
- [ ] `renderChatMessageHTML`: у игроков кнопки в сообщениях убираются, у ведущего работают и после
      перезагрузки чата.
